---
name: grill-me
description: Grill the user on a plan or design until shared understanding is reached. Use when the user wants to be grilled or a plan stress-tested.
---

Run the **grill** loop — see the `grilling` skill. grill-me is the bare interview: that loop with nothing layered on.

**Stop at understanding.** The deliverable is the shared understanding, not code. Once the grill settles and the user confirms it, hand onward as a separate, explicit step (`to-spec` -> `to-tickets` -> `implement`) — rolling straight into implementing the plan is the failure mode here.
