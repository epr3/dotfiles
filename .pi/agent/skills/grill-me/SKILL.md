---
name: grill-me
description: Grill the user on a plan or design until shared understanding is reached. Use when the user wants to be grilled or a plan stress-tested.
---

Run the **grill** loop (see the `grilling` skill). grill-me is the bare interview: that loop with nothing layered on.

**Stop at understanding.** The deliverable is the shared understanding, not code. Once the grill settles and the user confirms it, report the shared understanding and suggested next step, then stop. Confirmation approves the understanding, not a workflow transition. Any next step requires a separate explicit user request.
