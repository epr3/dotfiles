---
name: grill-me
description: Grill the user on a plan or design until shared understanding is reached. Use when the user wants to be grilled or a plan stress-tested.
---

Run the **grill** loop (see the `grilling` skill). grill-me is the bare interview: that loop with nothing layered on.

**Stop at understanding.** The deliverable is the shared understanding, not code. Once the grill settles and the user confirms it, planning may flow onward into specifications and tickets as the workflow requires (`to-spec` -> `to-tickets`); no second request needed. Implementation and code changes stay a separate boundary; never start them without an explicit implementation request from the user.
