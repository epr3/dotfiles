---
name: grill-me
description: Grill the user on a plan or design until shared understanding is reached. Use when the user wants to be grilled or a plan stress-tested.
---

Run the **grilling** loop — see the `grilling` skill. grill-me is the bare interview: that loop with nothing layered on.

**Stop at understanding.** The deliverable is the shared understanding the interview reaches — not code. When the grilling settles, don't roll into implementing the plan; that eagerness is the failure mode. Acting on it is a separate, explicit step (`to-spec` -> `to-tickets` -> `implement`).
